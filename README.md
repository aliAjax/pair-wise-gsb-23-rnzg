# hxwl-09 半导体洁净室巡检

压差梯度判定、缓冲间通行闭环与跨班顺延复核看板。

## 技术栈

React + Vite + TypeScript + CSS（数据持久化使用 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 功能闭环

- **房间登记**：登记走廊压差、相邻房间及设计/实测压差方向、缓冲间在室人数。
- **三条规则判定**（任一命中，通行申请停在「待复核」）：
  - R1：房间登记走廊压差低于 5 Pa
  - R2：相邻房间压差实测方向与设计梯度倒置
  - R3：缓冲间在室人数达到 2 人
- **通行申请**：必须填写通行依据（作业单 / 事由）；无冲突时由班组长直接放行。
- **班组长放行**：待复核件填写复核依据后放行，放行瞬间冻结读数与缓冲间人数为 v1。
- **补录留旧值**：放行后数据不可就地覆盖，补录只追加带原因的新版本（v2、v3……），旧值原样保留可展开对比。
- **跨班顺延**：换班时仍「待复核」的申请自动追加顺延记录（夜班 → 白班 …），不丢失、不自动放行。
- **刷新一致**：申请、放行版本、顺延链持久化到 localStorage，刷新后状态一致。
- **冲突面板**：固定列出房间、走廊压差、缓冲间人数、命中规则与判定说明。

## 分层结构

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 数据 | `src/data/store.ts` | 种子数据、reducer 状态变更、localStorage 读写，不含阈值规则 |
| 判定 | `src/domain/types.ts` `src/domain/rules.ts` | 领域模型与纯函数规则（压差、方向、人数、顺延），不依赖 React |
| 页面 | `src/ui/*`、`src/App.tsx` | 登记表、冲突面板、申请/复核/放行/补录界面 |

## 角色与演示

- 巡检员 / 厂务工程师：登记读数与人数、提交申请、对已放行件补录新版本。
- 班组长：只读看板，在待复核队列填写依据后放行。
- 侧栏可切换班次（演示跨班顺延）、角色，并可恢复种子演示数据。
